# MJ's MotoShop | Sales & Inventory Analytics Dashboard

An interactive Power BI dashboard designed to monitor and analyze motorcycle parts sales, inventory levels, product performance, and business profitability.

This project transforms motorcycle shop sales and inventory data into meaningful insights that can support better business decisions, improve stock monitoring, and track overall business performance.

## Project Overview

MJ's MotoShop is a data analytics project focused on motorcycle parts retail operations. It provides a centralized view of important business metrics through interactive dashboards and visual reports.

The dashboard allows users to monitor sales performance, evaluate inventory conditions, identify fast-moving products, and compare motorcycle models and parts categories.

## Project Objectives

- Monitor overall sales and revenue performance.
- Track inventory levels and stock availability.
- Identify low-stock and out-of-stock products.
- Analyze product performance across motorcycle models.
- Evaluate business profitability and transaction trends.
- Provide data-driven insights to support inventory and sales decisions.

## Dashboard Modules

### 1. Overview Dashboard

Provides a summary of the shop's overall performance through key performance indicators (KPIs), including:

- Total Revenue
- Total Profit
- Total Stock Value
- Total SKU
- Total Units Sold
- Total Transactions

### 2. Inventory Dashboard

Focuses on stock monitoring and inventory management.

- Low-stock monitoring
- Out-of-stock product tracking
- Aging inventory analysis
- Stock value monitoring
- Inventory category analysis

### 3. Models Dashboard

Analyzes motorcycle parts based on their associated motorcycle models.

Models covered:

- Bajaj
- Beat
- Click 125
- Kawasaki
- Raider 150
- Rusi
- TMX
- Universal
- Wave 125

### 4. Sales Dashboard

Provides insights into sales transactions and business performance.

- Revenue analysis
- Profit analysis
- Units sold
- Average Order Value
- Transaction trends
- Product sales performance
